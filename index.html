收測數量彙總

把所有收測案件的第一手數量彙成一張 CSV， 供估驗計價、變更設計結算、驗收查核比對。每個案件匯出時， 資料夾裡也會附一份可列印的收方測量紀錄表。

拍照即備份

每拍一張，立刻在手機「下載」資料夾存一份， 檔名就是正式命名。就算還沒匯出、App 資料被清掉，照片也還在。

路證：自動查路名

新增路段時用手機 GPS 自動帶入路名（可手改）。 只會送出座標去查路名，不會送出任何照片。沒網路時仍會記錄座標，之後可補查。

怎麼用

  1. 現場開 App →「新增拍照案件」→ 選工項、填檢查位置、確認日期。
  2. 照格子順序拍，每格可以連拍好幾張（預設建議 3 張），日後挑一張用。
  3. 覺得哪張最好，按「★首選」，它就會排在最前面（檔名 -1）。
  4. 拍完 →「匯出」→ 手機下載資料夾多一個 ZIP → USB 接電腦拖走。

檔名長這樣

資料夾：1150715_試挖_忠明南路福德街口(A3-1A)

同一格拍 3 張時：

…_03-1_試挖長度量測 長3.0M.jpg
…_03-2_試挖長度量測 長3.0M.jpg
…_03-3_試挖長度量測 長3.0M.jpg

注意

  • 照片存在手機瀏覽器裡，當天拍完就匯出，不要放好幾天。
  • 匯出後案件仍留著，可以重新匯出；確定電腦收到了再刪除以釋放空間。
  • 沒有網路也能拍、能匯出，全程不需連線。
